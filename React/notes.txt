React works on components, basically legos if you had to make the legos yourself.

The return function only returns one element, but multiple elements can be placed insde of that element to return multiple.
In the main function (here it's App.jsx), we can return multiple components by putting them in a fragment (inside '<>' and '</>')

In a jsx file, to use JS in the return function, we need to wrap the code with '{}'.
Outside the return function, we can write JS straight up as long as it's inside the bigger function.

Part 3: Add CSS Styles
1. External: index.css
    *Can become too big and hard to manage in larger projects
    *Can cause naming conflicts
2. Modules: basically make a separate folder housing both the component and its styling
    *Avoids naming conflicts
    *Requires more setup
    *Global styles aren't applied easily 
3. Inline
    *Easy to understand
    *Prevents global style conflicts
    *Great for components with individual styling
    *Not maintainable in large projects for more complex styling

Part 4: props [defaultProps deprecated in React 19+]
props are real-only properties that are shared between components.
A parent component can send data to a child component.
Syntax = <Component key=value/>

If the value is not a string, it needs to be wrapped in {}
Boolean values don't display directly to the DOM, they need to be part of a conditional statment, like a ternary operator

propTyps: a mechanism that ensures that the passed value is of the correct datatype
Example: age: PropTypes.number

In new React (19+) you to manually download prop-types (usin npm install prop-types) in the directory if you are using standard JS

Part 6: Rendering Lists
Need to turn array of values into list elements using the map method before they can be printed as such
If printing objects, each object needs a key attribute in it's corresponding list element, each key should be unique to that object
&nbsp; : used to put in a tab in the message
fruits.sort((a, b) => a.name.localeCompare(b.name)); : Alphabetical order
fruits.sort((a, b) => a.calories - b.calories); // Numeric order
for revere alphabetical or numberic order, just switch 'a' and 'b'
const highCalFruits = fruits.filter(fruit => fruit.calories >= 100); : Example of filtering data

{fruits.length > 0 && <List items={fruits} category="Fruits"/>} : can be used to conditionally display a list
The && (and) operator can be used as a shortcut for the terniary operator since we only want to display the list when both cases are true
As long as the list actually exists, the corresponding "<List items={fruits} category="Fruits"/>" portion will be true
Also known as short circuiting

Part 8: .useState() hook
React Hook: Special function that allows functional components to use React features without writing class components.
(useState, useEffect, useContext, useReducer, useCallback, etc.)

useState() : A React hook that allows the creation of a stateful variable and a setter function to update its value in the virtual DOM.
[variable, function]

Regular JS won't be able to change the value of the variable (like name) without using the predefined function (like setName)
When you use the setter function of a stateful varible, it triggers a rerender of the virtual dom, normal variables don't
