Part 11: Updater Functions
An updater function is a function passed as an argument to setState() usually.
ex. setYear(year + 1), would be better to do this: setYear(y => y + 1)
Allows for safe updates based on previous data state (here its y).
Used with multiple state updates and asynchronous functions.
Good practice to use updater functions.

I'm changing the Counter component for this one.

The setter function established for a statefull variable only uses the current state of the variable to perform updates.
so like:
setCount(count + 1);
setCount(count + 1);
only makes count got up by 1 since both times use the same orignial count value
This is because React batches together state updates

When using arrow functions, it is recommended to take use the first letter of the state variable being changed as the input
React puts updater functions in a queue for execution

Part 16: useEffect() Hook
useEffect is a React hoock that tells react to do some code when:
* This component re-renders
* This component mounts
* The state of a value
Syntax: useEffect(function, [dependencies])
1. useEffect(() => {}) runs after every re-render
2. useEffect(() => {}, []) runs only on mount
3. useEffect(() => {}, value) runs on mount and when value changes

Used in:
1. Event Listeners
2. DOM manipulation
3. Subscriptions (real-time updates)
4. Fetching data from an API
5. Clean up when a component unmounts

Basically just some side code

Using MyComponent6 for this.

Place useEffect() near the top of your component

Technically the code inside of useEffect can still run without it wrapping it in some cases,
but it keeps the code more organized and easier to read, and it may lead to unexpected code running when you don't want to without useEffect.

Mounting means adding a component to the DOM and unmounting means removing it from the DOM.

Part 18: useContext() Hook
The useContext() hook allows you to share values between multiple levels of components without passing props thorugh each level.

Passing props down through consequent components (Child components) is called prop drilling.

To use useContext(), we need to set up a *Provider Component*
1. import {createContext} from 'react';
2. export const MyContext = createContext();
3. <MyContext.Provider value={value}>
    <Child />
   </MyContext.Provider>

Any component that needs this data, we set them up to be a *Consumer Component*
1. import React, {useContext} from 'react';
   import {MyContext} from './ProviderComponent'
2. const value = useContext(MyContext);
