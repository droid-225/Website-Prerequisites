REPL is for playing around, CLI is for everything else.
To access REPL, we can either use the NodeJS app or just type "node" and then enter in the terminal.
CLI can just be used through VSCode or any other IDE

Created first.js for this.
To run this, we can either use the windows terminal by using node first.js or just using the terminal in VSCode and use node first.js

NPM Commands
-> Node Package Manager
-> External modules (dependecies/package), basically just pre-made JS code we can use in our projects
-> You can search for packages on npmjs.com

npm automatically creates the node_modules folder to store all installed npm packages.
Installing packages also installs thier dependecies.

You need to place the node_modules folder in the gitignore file so you don't also share extra dependecies when sharing our package.
The person who uses our package can just use "npm install" to download all required packages since they should already be specified in the package.json file.
